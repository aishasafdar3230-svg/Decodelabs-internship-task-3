Shopping Hub

Project Description

Shopping Hub is a responsive e-commerce website developed using HTML, CSS, and JavaScript. It allows users to browse products, search products, filter products by category, add items to the shopping cart, and manage the cart using Local Storage.

---

Features

- Responsive Design
- Home Page
- Products Page
- About Page
- Contact Page
- Shopping Cart
- Product Search
- Category Filter
- Add to Cart
- Remove from Cart
- Local Storage
- Contact Form Validation

---

Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

---

JavaScript Concepts Used

- DOM Manipulation
- Event Listeners
- Local Storage
- Form Validation
- Functions
- Arrays
- Objects
- Loops
- Conditional Statements

---

Note

This project is developed using Front-End technologies only. No back-end or database has been used.
